Сервис бронирования общих ресурсов

Десктопное приложение на C# (WPF, .NET Framework 4.7.2) для бронирования общих ресурсов организации: переговорки, оборудование, фотографы.

## Что делает приложение

- Календарь ресурсов — просмотр занятости по дням, временные слоты с 08:00 до 20:00
- Бронирование ресурса с выбором даты, времени, сотрудника и цели
- Проверка на повторное бронирование (конфликт времени не пропускается)
- Уведомления сотрудников о новом бронировании и синхронизация с календарём
- Управление ресурсами (добавление, редактирование, удаление, ответственные)
- Управление пользователями (сотрудники, роли Administrator / Employee)

## Технологии

- C#, WPF, .NET Framework 4.7.2
- MVVM (без сторонних библиотек)
- Данные хранятся в XML-файлах в папке `service/Data/`

## Как запустить

1. Откройте `service.slnx` в Visual Studio 2017 или новее.
2. Выберите конфигурацию Debug и нажмите F5.
3. При первом запуске создадутся демо-пользователи и ресурсы.

## Структура

```
service/        # основной WPF-проект
  Models/       # модели данных
  Services/     # сервисы бронирования, уведомлений, работы с данными
  ViewModels/   # view-модели (MVVM)
  Views/        # окна приложения
```

## Примечание

Папки `bin/`, `obj/`, `.vs/` и XML-файлы данных в `service/Data/` не входят в репозиторий (добавлены в `.gitignore`).
