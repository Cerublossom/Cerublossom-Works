# Сервис бронирования общих ресурсов

Учебный проект (курсовая работа): десктопное приложение на **C# + WPF** для бронирования общих ресурсов организации — переговорных комнат, оборудования и фотостудии.

Интерфейс сверстан по дизайн-макету: тёмно-зелёная фотография-шапка с навигацией, светлые страницы, карточки ресурсов с фотографиями и зелёные «пилюли» часовых слотов.

Репозиторий: https://github.com/Cerublossom/Cerublossom-Works

## Возможности

- **Календарь ресурсов** — занятость по выбранную дату, слоты ровно по часу с 08:00 до 20:00. Клик по свободному слоту сразу открывает форму бронирования с подставленными ресурсом, датой и временем (длительность — один час).
- **Бронирование** — выбор ресурса, даты, времени и сотрудника, для которого оформляется бронирование («Кем бронируется»), цель визита. Начало и конец задаются целыми часами.
- **Защита от двойного бронирования** — пересечение интервалов проверяется сервисом; пользователь видит предупреждение до сохранения.
- **Уведомления** — участники получают уведомление о новом бронировании и запись о синхронизации с календарём; есть отметка «прочитано» и счётчик непрочитанных.
- **Ресурсы** — добавление, редактирование, удаление, назначение ответственного сотрудника, активность ресурса и фотография (можно выбрать свой файл).
- **Люди** — карточки сотрудников с фотографиями, поиск по ФИО/email, сортировка, редактирование и удаление; календарь и список активных приглашений на выбранный день.
- **Вход и регистрация** — приветственный экран с выбором пользователя или созданием нового аккаунта.

## Технологии

- C#, WPF, .NET Framework 4.7.2
- Собственная реализация MVVM (`ViewModelBase`, `RelayCommand`) — без NuGet-пакетов
- Привязки и конвертеры вместо сложных XAML-триггеров
- Хранение данных — XML-файлы в папке `service/Data/`
- Фотографии ресурсов — ссылки на Wikimedia Commons (с заменой на локальные файлы `Images/`); аватары сотрудников — внешние портреты-заглушки. Без интернета показываются заглушки

## Как запустить

1. Откройте `service.slnx` в Visual Studio 2017 или новее.
2. Выберите конфигурацию **Debug** и нажмите **F5** (Clean → Rebuild перед первым запуском не помешает).
3. На экране входа выберите демо-пользователя или зарегистрируйтесь.
4. При первом запуске автоматически создадутся демо-пользователи и ресурсы.

## Структура проекта

```
service/
  App.xaml, MainWindow.xaml, WelcomeWindow.xaml
  Models/       # сущности: User, Resource, Booking, Notification
  Services/     # DataService, BookingService, NotificationService, DemoImages
  ViewModels/   # MVVM: MainViewModel, CalendarViewModel, BookingViewModel и др.
  Views/        # пользовательские элементы экранов
  Data/         # XML-хранилище (создаётся при запуске)
  Images/       # локальные фотографии ресурсов (по желанию)
```

## Примечание

Папки `bin/`, `obj/`, `.vs/` и XML-файлы данных в `service/Data/` не входят в репозиторий (добавлены в `.gitignore`). Проект рассчитан на Windows и Visual Studio с поддержкой .NET Framework 4.7.2.
