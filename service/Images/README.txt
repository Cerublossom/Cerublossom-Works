Фотографии ресурсов
===================

По умолчанию демо-ресурсам уже назначены фотографии с Wikimedia Commons
(свободные лицензии, ~960px). Они загружаются по ссылке при показе карточки,
поэтому для первого запуска нужен интернет.

Свои фото можно добавить двумя способами:

1. Через программу: "Управление ресурсами" -> карточка ресурса ->
   поле "Фото" -> кнопка "Выбрать...". Картинка скопируется в эту папку
   и сохранится в базе.

2. Вручную: положите файлы сюда и укажите путь в поле "Фото", например
   Images/room-a.jpg. При сборке папка Images копируется рядом с exe.

Если картинка не загрузилась, в карточке остаётся серая заглушка "ФОТО".
